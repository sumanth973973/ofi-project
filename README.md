# 📦 OFI Case Study — Predictive Delivery Optimization Dashboard

### 🚀 Project Overview
This project is part of the **AI Internship – OFI Case Study**, built using **Python, Streamlit, and Machine Learning**.  
It analyzes logistics data, predicts potential delivery delays, and visualizes operational insights through an interactive dashboard.

---

### ✨ Features
- ✅ **Integrates 6 datasets** (Orders, Routes, Delivery, Cost, Feedback, Inventory)
- 🤖 **Predicts delivery delays** using a Random Forest ML model
- 📊 **Visual analytics** via interactive charts (Plotly)
- ⚙️ **Real-time user inputs** for distance, fuel, and traffic
- 🧩 Modular and extendable for cost, fleet, and inventory analytics
